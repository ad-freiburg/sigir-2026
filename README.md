# Materials surrounding the SIGIR 2026 Full Paper Research Track

This repository contains the mails sent by the PC chairs, the queries
used for managing the process, for the mails, and for a variety of
statistics, and the OpenReview stages (forms and tasks) of the track:

- `mails/`: the mails, one file per mail, with placeholders for the
  personalized parts.
- `queries/`: the SPARQL queries, see the README there.
- `stages/`: the OpenReview forms and tasks (called stages in OpenReview),
  from the initial check to the author feedback, one file per form, with a
  README explaining each.

For the `ortler` tool, see https://github.com/ad-freiburg/ortler
